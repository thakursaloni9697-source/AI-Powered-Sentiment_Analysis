# Sentiment Analysis using Fine-Tuned DistilBERT and Streamlit

An advanced, enterprise-grade AI dashboard for real-time sentiment analysis and token interpretability powered by a fine-tuned DistilBERT transformer and Streamlit.

## 🚀 Key Features
- **Batch Dataset Analytics & Visuals:** Upload CSV/Excel or generate synthetic domain datasets (E-Commerce, Finance, Tech Support) with automated inference progress tracking.
- **Interactive Token Inspector:** Real-time single-text inference with subword tokenization tables and attention heatmap simulations.
- **Advanced Visualizations:** Donut proportion breakdowns, confidence box plots, and polarity score density histograms using Plotly.
- **Multi-Format Export:** Instant data export to CSV, JSON, and styled Excel workbooks.
- **Minimalist Enterprise UI:** Clean, sophisticated styling optimized for executive presentations and GitHub portfolios.

---

## 🛠️ Quick Start

1. Clone or extract the repository:
   ```bash
   cd sentiment_analysis_distilbert
   ```
2. Create virtual environment and install dependencies:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Run the Streamlit application:
   ```bash
   streamlit run app.py
   ```
